# Product documentation

The Phase 12 launch-product definition is split into three focused contracts:

- [`launch-product-v1.md`](launch-product-v1.md) — primary persona, launch
  promise, scope, non-goals, Consumer/Pro boundary, capability matrix, success
  measures, and Phase 13 priority.
- [`golden-path-v1.md`](golden-path-v1.md) — all 16 launch steps with normal,
  loading, empty, error, accessibility, performance, telemetry, test, and
  acceptance requirements.
- [`release-entry-criteria-v1.md`](release-entry-criteria-v1.md) — alpha, beta,
  general-availability gates and human evidence ownership.
- [`product-decision-log.md`](product-decision-log.md) — defined, open, and
  human-owned decisions.
