# Scan, remodel and export a proposed plan

A scan is a reference for planning. Recognition can miss faint walls, confuse symbols or misread numbers. Review the source overlay, correct the geometry and confirm scale before relying on measurements. If independent dimensions conflict, use a clearer source or measured tracing; stretching the image does not resolve perspective distortion. Optional artwork is not automatically a wall or a room.

In **Set and check scale**, select the two ends of a printed dimension and enter its length in millimetres, centimetres, inches or feet and inches. The input shows the integer millimetres that will be saved, including rounding. Changing display units keeps the entered length unchanged. **Cross-check scale** records another dimension without resizing geometry; choose a different span, preferably in the other direction. Clean drawings use a 2-source-pixel check tolerance and scans use 3. These checks do not certify whole-plan accuracy. A conflict remains in the saved review draft and blocks design creation until corrected or explicitly removed. Use **Edit check** to inspect its endpoints and correct its length. Checks retain their source endpoints, input units and historical residuals; their current disagreement is recalculated whenever scale changes. A single measurement alone cannot establish accuracy across the plan.

In Consumer Mode, open the imported-wall controls and choose **Edit this plan** to create a private proposed version. The original reference remains available for comparison. Select a wall to change its numeric dimensions, move its endpoints, or add/remove a proposed partition. Removal lists hosted doors/windows and asks which room's name and finishes to retain. A full valid partition divides a room; a partial wall remains a partial wall. Digital removal is a conceptual design change and does not establish whether demolition is permitted.

Wall and opening controls, 2D/3D views, placement checks and vector export use the same accepted plan. A completed drag or confirmed numeric edit is one undoable change; Escape cancels an active drag. Check new placement warnings after changing walls. Intersecting furniture is preserved for correction, and saved room layouts remain available for recovery.

In **Compare and export vector plan**, choose paper, orientation and a fixed scale of 1:50 or 1:100. Choose a larger page or 1:100 if the drawing does not fit. Print at 100%: a 9260 mm plan dimension measures 92.6 mm at 1:100. Dimensions show live proposed millimetres measured along the stated centreline convention. Historical source numbers do not replace current measurements.

The PDF and SVG contain separate wall, window, door, swing, fixture/furniture and text objects. Dimensions, labels and fixtures/furniture can be toggled. Unknown furniture dimensions and unsupported details are reported. Curved wall footprints currently use sampled segments; the exporter does not claim precise curved-wall editability.

The default clean drawing excludes the original image. **Reference underlay** explicitly includes the existing image as a separate raster object behind the vectors, preserving its registered placement, rotation, skew or reflection, and opacity. These transforms retain the existing registration; export does not infer a new distortion correction. Visible names or old markings in the image are included when selected. Embedded image metadata and source filenames/URLs are omitted. The full rotated image must fit the selected paper at the declared scale. Export checks private import access and source deletion; a failed source check does not fall back to cached image bytes. Export a clean drawing if the reference is unavailable.

The editable export embeds Liberation Sans Regular for display. Install the supplied [font](../../../public/fonts/liberation-sans/LiberationSans-Regular.ttf) if Illustrator requests it; its [SIL Open Font License](../../../public/fonts/liberation-sans/OFL.txt) permits embedding and redistribution. Missing glyphs or unsupported text shaping cause an explicit error. Labels are kept as text, never silently removed or converted to outlines. Embedded display glyphs alone do not prove that Illustrator can edit text without a locally available font.

Native Illustrator 2024 acceptance is still pending. Open the PDF as artwork, rather than placing a linked page, and follow [the acceptance checklist](ILLUSTRATOR-ACCEPTANCE.md) to verify independent selection, character editing, save and reopen. The SVG is a separate companion test, not a substitute for PDF acceptance. Neither format contains proprietary Illustrator editing data or a promised Illustrator layer hierarchy.
