# Admin condo map

`/admin/condo-map` shows the developments from the floor-plan masters on a Mapbox map, each on its own site: the
whole building as grey massing (33 Residences as its detailed 3D models), a chosen floor cut open with its units' rooms
painted on it, and a chosen unit's card with its plan. It is admin-only and unlisted (not in the admin menu) while J
decides what it becomes. J's choices, 24 Oct 2026: admins only; all nine developments. 25 Oct 2026: 32 Gilstead
added, so ten (each new development in the masters joins the map with a re-export).

## Decisions

- **Mapbox GL JS from its CDN, not a dependency.** The map is an admin preview, and its library is 1.9 MB.
  `app/admin/condo-map/useMapboxGl.ts` loads `mapbox-gl@3.31.0` from jsDelivr only on this page, with each file
  pinned to its version and checked by its SRI hash, so a changed file doesn't run. The types it uses are local
  (`mapbox-gl-types.ts`). A new version means new hashes (and a look at the map).
- **A public token only, read on the server.** `MAPBOX_PUBLIC_TOKEN` must be a `pk.` token (anything else counts as
  none, so a secret `sk.` token can't reach a browser); restrict it in Mapbox to the app's URLs. Without one the page
  still lists the developments and units and says what the map needs.
- **The data stays behind the admin check.** The developments' files live in `catalog/condo-map` (generated by the
  masters' `_tools/mapexport/export_condo_map.py`; see its README) and reach the browser only through
  `/api/admin/condo-map/[...path]`, which checks admin access first and serves only `<slug>/map.json`,
  `<slug>/plans/<picture>` and `<slug>/models/<model>.glb` (`lib/condo-map/condo-map-paths.ts`). `next.config.ts`
  traces the folder into that route and the index into the page. The data is checked as it is read
  (`lib/condo-map/condo-map-data.ts`), so a changed export fails loudly.
- **33 Residences' models are in Git LFS** (`*.glb`), like the catalogue's models.
- **What a view shows is pure and tested.** `condo-map-view.ts` (choosing a development, floor or unit; a unit brings
  its floor) and `condo-map-layers.ts` (the sources, layers, filters and colours) don't touch Mapbox;
  `scripts/test-condo-map.ts` runs the filters against the real features. `condo-map-mapbox.ts` does the Mapbox work
  and the hooks call it from their effects.
- **Mapbox's old buildings are kept off the sites** by a clip layer on each footprint 2.5 m in, and, where a browser
  draws one anyway (Safari did in the prototype), by marking it "selected", which the map's config draws clear
  (`condo-map-basemap.ts`).
- **Credits.** Each development's credits (the brochures; SLA's land lots under the Singapore Open Data Licence;
  OneMap) are shown under the map, as the licences ask. No tiles or satellite pictures are stored.

## Checks

`npm run test:condo-map`; the admin authorization test covers the page and the route.
