# Liberation Sans Regular

Unmodified Liberation Sans Regular supplied by the existing `pdfjs-dist` package (`standard_fonts/LiberationSans-Regular.ttf`). The accompanying `OFL.txt` is its `LICENSE_LIBERATION`, including copyright notices and SIL Open Font License 1.1, which permits redistribution and embedding. No font modification or rename was made.

- File size: 139512 bytes.
- SHA-256: `f8ace1f892b2bd9dc1792ba7f097fa7588f84fed48321480e04de5390828221f`.

The plan PDF exporter embeds this full font program and keeps text as text. The SVG includes the same font as an embedded display font. Illustrator may still need the font installed to edit text without substitution. Embedding alone does not demonstrate editable typography in Illustrator. Install the supplied TTF if requested and inspect font substitution when opening the artwork.

The exporter rejects missing glyphs and shaping it cannot preserve, instead of dropping text or converting it to outlines. This font is not a claim of complete multilingual support.
